# Mind-Wave / Gesture Runner Game

A dynamic, Chrome Dino-style runner game built with Python and Pygame.
The unique twist? It uses your laptop's webcam and **MediaPipe** to track your hand gestures. 
- Raise your hand/index finger to **jump**!
- Lower your hand or close it to **duck**!

## Tech Stack
- **Python**
- **Pygame** (Game logic and rendering)
- **MediaPipe & OpenCV** (Hand tracking and gesture recognition)
